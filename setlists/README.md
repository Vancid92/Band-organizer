# Setlists

One markdown file per set: `YYYY-MM-DD-venue-slug.md` (rehearsals can reuse a gig file or use `YYYY-MM-DD-rehearsal.md`).

Link the path from `band/gigs.csv` or `band/rehearsals.csv` (`setlist_path`).

## Template

```markdown
# Setlist — <Venue or rehearsal>
- Date: YYYY-MM-DD
- Gig / rehearsal: G0001 or R0001

## Set 1
1. Song title (S0001) — key
2. ...

## Encore
1. ...

## Notes
- Target runtime:
-
```
